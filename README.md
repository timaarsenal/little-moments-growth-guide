# 🐣 Balapan — развитие ребёнка в минуты, которые у вас уже есть

**Balapan** (каз. «птенец») — ИИ-помощник для занятых родителей детей 0–3 лет. Приложение подбирает короткие развивающие занятия под возраст ребёнка, его интересы, режим сна и свободное время семьи.

🔗 **Приложение:** https://little-moments-growth-guide.lovable.app
🏆 Проект для конкурса **Tech Orda DevShow** · трек **Digital Impact**

---

## Проблема

Родители хотят вкладываться в развитие ребёнка, но у них нет времени: работа, учёба, быт. Советы в интернете разрозненные, рассчитаны на «идеального» родителя и не учитывают возраст в месяцах, дневной сон и реальный график семьи. В итоге — чувство вины и время с ребёнком, которое проходит без пользы для развития.

Мы сами родители двухлетнего сына и сталкиваемся с этим каждый день.

## Решение

Balapan не просит у родителей выделить час на развитие — он превращает в развитие те минуты, которые уже есть.

| Функция | Что делает |
|---|---|
| **План на сегодня** | Занятия 5–15 минут в свободные окна родителей, мимо дневных снов |
| **«Есть 5 минут?»** | Выбираете, где вы сейчас (кухня, ванная, машина), — получаете занятие из того, что под рукой |
| **Интересы ребёнка** | Машинки, животные, музыка — занятия строятся вокруг того, что любит малыш |
| **Режим сна** | Несколько дневных снов с подсказками по возрасту; перед сном — только спокойные занятия |
| **Ритуалы** | Повторяющиеся действия (ванна → книжка → колыбельная), которые дают малышу предсказуемость |
| **Моменты** | Фото важных моментов в закрытом семейном альбоме |
| **ИИ-помощник** | Чат: обсудить занятие, спросить совет, получить поддержку, если родитель устал |
| **Прогресс** | «Минуты вместе», серия дней, занятия по категориям, этапы развития |
| **Қазақша** | Интерфейс на русском и казахском, занятия с казахскими словами и счётчик новых слов |
| **Погода** | В мороз или метель прогулка заменяется активной игрой дома |

## Как это устроено

```
Родитель (телефон / браузер)
        │
        ▼
Веб-приложение: React + TanStack Start, RU/KZ
        │
        ├──► Lovable Cloud (Supabase): PostgreSQL, авторизация, хранилище фото
        ├──► ИИ через Lovable AI Gateway: подбор занятий (JSON) и чат-помощник
        └──► Open-Meteo: погода для адаптации плана
```

**Безопасность контента:** ИИ подбирает и адаптирует занятия на основе встроенной библиотеки и учитывает возраст ребёнка, а не придумывает упражнения с нуля. Для занятий с мелкими предметами и водой показывается предупреждение о присмотре взрослого.

## Технологии

- **Frontend:** React 19, TypeScript, TanStack Start / Router / Query, Vite, Tailwind CSS 4, Radix UI, Recharts
- **Backend:** Lovable Cloud на базе Supabase — PostgreSQL, Auth, Storage; Drizzle ORM для миграций
- **ИИ:** Lovable AI Gateway + Vercel AI SDK (стриминг ответов в чате)
- **Внешние данные:** Open-Meteo (погода, без ключа)
- **Качество:** TypeScript, ESLint, Prettier, автотесты на Vitest и Testing Library

## Структура репозитория

```
src/        — приложение: страницы, компоненты, логика, переводы RU/KZ
supabase/   — конфигурация и миграции облачной базы данных
drizzle/    — схема и миграции базы данных
public/     — статические файлы
```

## Источники контента

- Этапы развития — по материалам CDC «Learn the Signs. Act Early.» (https://www.cdc.gov/act-early/)
- Рекомендации по сну, активности и экранному времени для детей до 5 лет — ВОЗ (WHO, 2019)

Приложение не заменяет консультацию педиатра.

## Запуск локально

Нужен Node.js 20+.

```sh
git clone https://github.com/timaarsenal/little-moments-growth-guide.git
cd little-moments-growth-guide
npm i
npm run dev      # запуск в режиме разработки
npm test         # автотесты
```
